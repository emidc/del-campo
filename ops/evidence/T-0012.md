## Qué NO se verificó

- **Rollback de una migración individual ya aplicada.** El runner de T-0010 no lo
  soporta y esta tarea no le agrega esa capacidad (ver la nota de reconstructibilidad
  arriba). Lo verificado es reset + reaplicación desde cero, no un `down` por
  migración.
- **CI real con el servicio de Postgres.** `.github/workflows/**` está denegado para
  este agente (R-13, R-15). El diff está propuesto en `REVIEWS/T-0012/` con los
  comandos exactos para aplicarlo, pero no se ejecutó en un runner de GitHub Actions;
  hasta que una persona con permiso lo aplique, el job de CI de este PR fallará en
  `pnpm test` por falta de `DATABASE_URL`/Postgres. Es un bloqueo humano pendiente, no
  maquillado con un skip.
- **INV-001, INV-002, INV-004, INV-005, INV-007 a INV-010, INV-013 a INV-019,
  INV-PV-001, INV-PV-002, INV-PV-005, INV-PV-006, INV-021.** Tienen mecanismo
  documentado en el schema o en D-0051 (por ejemplo, INV-PV-001/INV-021 vía FK
  `NOT NULL`, INV-PV-002 vía `UNIQUE`), pero no todos tienen un test de integración
  dedicado: la tarea pidió explícitamente cuatro violaciones (solapamiento,
  segunda-versión-abierta, dos roles activos, ciclo de merge) más lo necesario para
  cerrar `## Verification`; se agregaron además INV-020, INV-022 e INV-023 porque
  costaban poco y reforzaban la evidencia, pero no se escribió un test por cada una de
  las 23 invariantes de §67 más las 6 de PolicyVersion.
- **Rendimiento del trigger de INV-003 sobre cadenas de merge largas.** El mecanismo
  es O(longitud de la cadena); no se midió con datos de escala real porque no existen
  todavía (T-0012 no importa nada).
- **Carga concurrente.** Los `EXCLUDE` y triggers se probaron con escrituras
  secuenciales dentro de una transacción; no se ejecutó ningún test de dos conexiones
  escribiendo en paralelo sobre la misma `Policy`/`Party`.
- **`pnpm decisions`** no se corrió como parte de esta verificación más que para
  confirmar que el checker de `decisions.yaml`/ADRs (dentro de `pnpm check`) sigue en
  verde con las tres decisiones nuevas; no se revisó manualmente su salida human-readable
  completa.
